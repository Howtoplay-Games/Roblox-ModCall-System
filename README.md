# 📞 Roblox Mod Call System

A **lightweight, server-secured mod call module** for Roblox games. Built to safely notify staff and forward alerts to Discord with minimal setup and clean, readable code.

## ✅ Features

- [x] **Server-side validation** (anti-exploit)
- [x] **Group role-based delivery**
- [x] **Discord webhook support**
- [x] **Readable & easy-to-edit code**
- [x] **Spam & misuse prevention**
- [x] **Configurable cooldowns**

## ⚙️ Highlights

- Requests handled strictly on the server  
- Alerts sent only to authorized group roles  
- Discord logging for external moderation  
- Minimal configuration, quick integration  

## 🛠️ Customization

- Group ID & allowed role ranks  
- Webhook URL & message format  
- Cooldown and validation rules  

---

Simple, secure, and designed to fit directly into existing moderation workflows.
